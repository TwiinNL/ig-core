This implementation guide contains the FHIR R4 artifacts that are shared by multiple Twiin implementation guides, such as the Twiin Notifications and Twiin Workflow guides. It is part of the technical core of the Twiin Afsprakenstelsel.

This version does not contain any artifacts yet.

### Status of this version

The normative status of a version of this implementation guide follows from the release of the Afsprakenstelsel that references it. A version is normative only as far as, and as long as, a release of the Afsprakenstelsel refers to it.
